# Portfólio — Rafael Matheus

Portfólio pessoal com foco em infraestrutura e back-end, desenvolvido como atividade da faculdade. O site apresenta quem eu sou, minhas habilidades técnicas, minha formação e os projetos que desenvolvi.

## Seções

- **Sobre mim:** apresentação e objetivos profissionais
- **Habilidades Técnicas:** cards com as tecnologias que utilizo
- **Formação:** cursos e instituições
- **Projetos:** Batcomputer, Monitor de Servidor, Scanner de Rede e AvoCredit (com modal de detalhes)

## Recursos

- Navegação em página única: o JavaScript alterna as seções sem recarregar a página
- Layout responsivo com grid e componentes do Bootstrap
- Botão de troca de tema (padrão e roxo) usando variáveis CSS
- Fundo animado com partículas
- Rodapé com links para GitHub, LinkedIn e Instagram

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.0.2
- Bootstrap Icons
- tsParticles
- Fonte IBM Plex Mono (Google Fonts)
