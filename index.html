AvoCredit

Sobre o projeto

Um sistema que analisa o perfil de pessoas de baixa renda, levando em consideração fatores como o histórico de pagamento de dívidas, o histórico de endividamento, problemas com casas de apostas, entre outros. O foco são as regiões Norte e Nordeste, com o objetivo de ampliar o score bancário dessas pessoas.

Minha participação

  • Desenvolvi os gráficos e dashboards a partir dos dados disponíveis.
  • Dockerizei o projeto: coloquei toda a nossa API em um container Docker.
